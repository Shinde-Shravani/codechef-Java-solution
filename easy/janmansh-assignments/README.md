# 🧩 Janmansh and Assignments

## 🔗 Problem Link
https://www.codechef.com/problems/ASSIGN

## 📝 Problem Summary

Janmansh has **3 assignments**, each taking **1 hour**.

- He starts at time **X**
- He must finish before **10 PM**

👉 Determine if he can complete all assignments on time.

## 💡 Approach

- Total time required = **3 hours**
- Available time = **10 - X**

Condition:
10 - X >= 3

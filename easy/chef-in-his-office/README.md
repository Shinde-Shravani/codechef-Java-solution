# 👨‍🍳 Chef in His Office

A simple Java solution for the CodeChef problem **"Chef in His Office"**.

## 📌 Problem Statement

Chef recently joined a company where:

- Employees work **X hours per day** from **Monday to Thursday**.
- **Friday is Chill Day**, so employees work only **Y hours**.
- **Saturday and Sunday are holidays**.

The task is to calculate the **total working hours in one week**.

### Formula

Total Working Hours = (4 × X) + Y


## 💻 Language Used

- Java

## 🚀 Approach

1. Read the number of test cases `T`.
2. For each test case:
   - Read `X` and `Y`.
   - Calculate:
     ```text
     Total Hours = (4 × X) + Y
     ```
3. Print the result.
